            महत्त्वाचे API स्टेटस कोड (Quick Status Reference):
          

          

            

              200 OK: API Key चालू आहे आणि विनंती यशस्वी झाली.
            

            

              401 Unauthorized: अवैध, खोटी किंवा कालबाह्य (expired) API Key.
            

            

              403 Forbidden: परवानगी नाही (Billing, Scope किंवा देश निर्बंध).
            

            

              429 Rate Limit: विनंत्यांची मर्यादा ओलांडली किंवा मोफत कोटा संपला.
            

            

              500/503 Error: सर्व्हर डाऊन किंवा API कंपनीकडील तात्पुरता बिघाड.
            

            

              CORS / Network: ब्राउझर सुरक्षा निर्बंध (Proxy चेकबॉक्स वापरा).
